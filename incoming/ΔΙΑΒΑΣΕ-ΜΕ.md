# Χειροκίνητη ενημέρωση (μόνο αν χρειαστεί)

Κανονικά δεν χρειάζεται να βάλεις τίποτα εδώ: η ενημέρωση γίνεται μόνη της κάθε Δευτέρα.

Αν κάποια φορά η αυτόματη λήψη από το minagric αποτύχει, κατέβασε με το χέρι από το 1click.minagric.gr:
- τη **Βάση Δεδομένων** («Κατεβάστε από εδώ», αρχείο .zip ή .mdb)
- τον **Κατάλογο Υπουργικών Αποφάσεων Φυτοπροστατευτικών Προϊόντων μετά την 1/1/2016** (.xls)

και ανέβασέ τα εδώ (Add file → Upload files → Commit). Η ενημέρωση ξεκινά αμέσως και τα αρχεία σβήνονται μόλις τελειώσει.
